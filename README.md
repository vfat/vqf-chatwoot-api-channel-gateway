# VQF Chatwoot API Channel Gateway

Gateway / middleware penghubung antara berbagai kanal perpesanan eksternal dengan fitur **API Channel** pada [Chatwoot](https://www.chatwoot.com).

## Fitur Utama (Rencana)

- **Bidirectional Bridging**: Menghubungkan alur Ingress (pesan masuk dari channel eksternal ke Chatwoot) dan Egress (balasan agen dari Chatwoot ke channel eksternal).
- **Channel Adapters**: Dukungan multi-kanal yang terisolasi dan modular.
- **Media Support**: Pengiriman pesan teks dan lampiran media (gambar, audio, dokumen).
- **Evidence-Based Documentation**: Dokumentasi arsitektur dan perancangan terpusat di `.ai-doc/`.
